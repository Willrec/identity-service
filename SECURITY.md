# Security Policy

We take the security of our services seriously. If you believe you have found a security vulnerability in this project, please report it to us as detailed below.

## Supported Versions

Security updates are actively applied to the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security vulnerabilities by emailing the maintainers or using GitHub's built-in Private Vulnerability Reporting feature:

- **Email**: security@elevo.app (placeholder for public releases - please update with your security inbox)
- **Response Timeline**: You can expect an acknowledgment of your report within 48 hours, along with a preliminary assessment of the issue and next steps.

Please include the following information in your report:
- A detailed description of the vulnerability.
- Steps or a proof-of-concept (PoC) to reproduce the behavior.
- Potential impact of the vulnerability.

## Security Update Process

Once a vulnerability is confirmed:
1. We will coordinate a fix and test it against all supported environments.
2. A security advisory will be published on GitHub.
3. Patch releases (e.g., v1.0.1) will be published immediately to address the issue.
